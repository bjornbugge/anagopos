\chapter{The parser and YAPPS2 parser generator (draft)}

We have used our grammar, as defined in the preliminaries chapter. We have
furthermore also kept the greediness, also defined in the the preliminaries
chapter.

We decided to use a parser generator because our needs for the parser was
fairly simple. There exist numerous parser generator for Python
\cite{pythonParserGeneratorList}, where we tried to locate one suitable for
our grammar. The parser generator we ended up choosing was the YAPPS2
\cite{YAPPPS2}, whish seemed to match our need fairly good. It is from 2003,
based on Python 1.5 and has the below focus points:

\begin{itemize}
	\item Easy to use
	\item Usable with simple grammars
	\item produces human-readable code
\end{itemize}

We made our decision based on the fact that our grammar is quite small, and if
we would need to edit the produced parser, it would be nice to have readable
code produced.

\section{Pre-processing}

We have chosen to run the lambda term through a pre-processing script before
parsing it. This pre-processing script adds all possible parentheses. We
decided on this pre-processing to make it easier to keep both the
left-associativeness and the greediness. Now the parser does not have to worry
about left-associativeness because the parentheses does this.
