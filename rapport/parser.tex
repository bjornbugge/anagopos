\chapter{The parser and YAPPS2 parser generator}

We decided to use a parser generator because our needs for the parser was
fairly simple. There exist numerous parser generator for Python
\cite{pythonParserGeneratorList}, where we tried to locate one suitable for
our grammar. The parser generator we ended up choosing was the YAPPS2
\cite{YAPPPS2}, whish seemed to match our need fairly good. It is from 2003,
based on Python 1.5 and has the below focus points:

\begin{itemize}
	\item Easy to use
	\item Usable with simple grammars
	\item produces human-readable code
\end{itemize}

Being easy to use was obviously a good thing, but the latter two matched the
best. Our grammar is quite small and if we would need to edit the produced
parser it would be nice to have readable code produced.

We have used our grammer, as defined in the preliminaries chapter, which looks
the following:

\begin{align*}
	x\in\Lambda \\
	M\in\Lambda &\Rightarrow (\lam{x}{M})\in\Lambda \\
	M, N\in\Lambda &\Rightarrow (M N)\in\Lambda
\end{align*}
