\chapter{The parser and YAPPS2 parser generator}

We have used our grammar, defined according to Definition \ref{def:grammar} in
the preliminaries chapter, which is followed by the conventions
\ref{con:con1} - \ref{con:con2}.

The steps needed for parsing a lambda term is two fold:
\begin{itemize}
	\item Pre-process lambda term to add needed parentheses
	\item Parse pre-processed term with the parser generated by YAPPS2 \cite{YAPPPS2}
\end{itemize}
When these steps are complete the reduction graphs can be created.

\section{Pre-processing}

We have chosen to run the lambda term through a pre-processing script before
parsing it. This pre-processing script adds all possible parentheses. This
solution was easier than to implement it into the grammar. We now fulfill the
conventions mentioned earlier in the chapter.

\section{YAPPS2}

We decided to use a parser generator due to our needs for the parser was
fairly simple. There exist numerous parser generator for Python
\cite{pythonParserGeneratorList}. The parser generator we chose was YAPPS2.
YAPPS2 generates code according to the Python 1.5 standard. Our primary reason
for choosing it was its production on human-readable code.

YAPPS2 takes a LL(1) grammar as input and gives a parser file as output. We
have, as earlier described, used the grammar from the preliminaries
chapter. This has been written in LL(1) form in a .py file and given as an
argument when running YAPPS2.
