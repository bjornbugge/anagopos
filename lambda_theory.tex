% and mathematics is represented with only functions and untyped variables that
% can be either free or bound.

As a very informal example, here is a function that doubles up an integer:
\begin{equation*}
	(\lam{x}{x+x})2=4.
\end{equation*}
This example shows a \emph{bound variable}, $x$, and an implicit \emph{reduction step}. The variable $x$
is said to be bound because the lambda function uses it as an argument. Contrast this to
\begin{equation*}
	(\lam{x}{x+y})2=2+y.
\end{equation*}
Here, $y$ is a variable that hasn't got any values assigned to it yet. From
the context we can say nothing about $y$, so we give it the predicate
``free''. In this second example there was yet another reduction step, which 
can be regarded as a rewriting action on the string representing the
lambda term. More informally, one can think of it as ``substituting in''
the values for the bound variables. In the examples above this amounts to
replacing $x$ with the number 2.

% definition af syntax
\subsection{Syntax}

The lambda calculus consists of \emph{lambda terms} and variables defined 
over the alphabet:
\begin{align*}
	x,y,z,\hdots\ &\text{ variables} \\
	\lambda\ &\text{ abstractor} \\
	()\ &\text{ parentheses}
\end{align*}
The set of all lambda terms is denoted $\Lambda$:
\begin{align*}
	x \text{ is a variable} &\Rightarrow x\in\Lambda \\
	x \text{ is a variable and } M\in\Lambda &\Rightarrow (\lam{x}{M})\in\Lambda \\
	M, N\in\Lambda &\Rightarrow (M N)\in\Lambda
\end{align*}
For brevity, it's conventional to leave out the outermost parentheses.
Evaluation is left associative, so $M N P = (M N) P$, and function
bodies extend as far as possible: $\lam{x}{M N}=\lam{x}{(M N)}\neq(\lam{x}{M})N$.
All lambda terms take exactly one argument, but as syntactic sugar we introduce
the following abbreviation:
\begin{align*}
	\lam{xy}{xy}\equiv\lam{x}{\lam{y}{xy}}
\end{align*}

% frie variable
\subsection{Free Variables}

As already indicated, the variables in a lambda term can be divided into
two groups; the free and the bound variables. The function $FV$ returns
for any lambda term the set of free variables:
\begin{align*}
	FV(x)&=\{x\} \\
	FV(\lam{x}{M})&= FV(M) - \{x\} \\
	FV((M N)) &= FV(M) \cup FV(N)
\end{align*}

\subsection{$\alpha$-congruence}

The particular name of a bound variable doesn't affect the function represented 
by a lambda term. Thus, the two terms
\begin{align*}
	\lam{x}{x} \\
	\lam{y}{y}
\end{align*}
denote the same function, the identity. For a term $M$ we define
\emph{change of bound variables} as a substitution of a part of $M$,
$\lam{x}{N}$, with $\lam{y}{(N[x:=y])}$, i.e. all occurences of $x$ are
replaced with an occurence of $y$. It is a requirement that $y$ doesn't occur
at all in $N$ in order for the substitution to be safe. We say that two terms
$M$ and $N$ are $\alpha$-congruent, $M\equiv_\alpha N$, if we can make $N$ from
$M$ by changing the bound variables. For instance, the following terms are
$\alpha$-congruent:
\begin{align*}
	\lam{x}{x}&\equiv_\alpha\lam{y}{y} \\
	\lam{x}{\lam{y}{xy}}&\equiv_\alpha{\lam{a}{\lam{b}{ab}}}
\end{align*}
whereas these terms aren't:
\begin{align*}
	\lam{x}{\lam{y}{xy}}\not\equiv_\alpha\lam{y}{\lam{y}{yy}}
\end{align*}
This last example illustrates the need for the requirement that $y$ cannot occur
in $N$.
In the following we'll use the short-hand $\equiv$ for $\equiv_\alpha$.

% definition af substitution af frie variable
\subsection{Substitution}
Substitution, written as:
\begin{align*}
	E[V:=E]
\end{align*}
Will substitute all free variables V with the expression X.\\
In lambda-calculus we have the notation:
\begin{align*}
	M[x:=N]
\end{align*}
It is defined as the following[\cite{Barendregt} 2.1.15]:
\begin{align*}
	x[x:=N]&\equiv N; \\
	x[y:=N]&\equiv y, if x \not\equiv y; \\
	(\lam{y}M_1)[x:=N]&\equiv\lam{y}(M_1[x:=N]) \\
	(M_1M_2)[x:=N]&\equiv(M_1[x:=N])(M_2[x:=N])
\end{align*}

% definition af undertermer
\subsection{Subterms}
A lambda term $M$ is composed of several parts which we call \emph{subterms}. 
$N\subset M$ notates that $N$ is a subterm of $M$. The subterms are defined by 
the function $Sub$:
\begin{align*}
	Sub(x) &=\{x\} \\
	Sub(\lam{x}{N}) &= Sub(N) \cup \{\lam{x}{N}\} \\
	Sub(M N) &= Sub(M) \cup Sub(N) \cup Sub(M N)
\end{align*}
A subterm $N$ of $M$ is called \emph{active} if $N L \subset M$ and \emph{passive}
otherwise.

\subsection{$\beta$-reduction}
A \emph{$\beta$-reduction} is a binary relation $\BETA\subseteq\Lambda^2$ such that
\begin{equation*}
	\BETA=\Big\{\big((\lam{x}{M})N,M[x:=N])\big)\big|M,N\in\Lambda\Big\}
\end{equation*}
For an element $(M,N)\in\BETA$, $M$ is called a \emph{$\beta$-redex} and
$N$ is called a \emph{$\beta$-contractum} of $M$. If a term $M$ doesn't contain
any subterms that are $\beta$-redexes, we say that $M$ is a \emph{$\beta$-normal-form}
($\beta$-nf).

The reduction captures the notion of ``substituting in'' terms for bound variables.
We have the relations (\cite{Barendregt} def. 3.1.5])
\begin{align*}
	(M,N)\in\BETA&\Rightarrow M\barrow N \\
	M\barrow N &\Rightarrow ZM\barrow ZN \\
	M\barrow N &\Rightarrow MZ\barrow NZ \\
	M\barrow N &\Rightarrow \lam{x}{M}\barrow \lam{x}{N} \\
	M\barrow N &\Rightarrow M\Barrow N \\
	M\Barrow N, N\Barrow L &\Rightarrow M\Barrow L \\
	M\Barrow M & \\
\end{align*}
These relations generate an equivalence relation:
\begin{align*}
	M\Barrow N &\Rightarrow M=_\beta N \\
	M=_\beta N &\Rightarrow N=_\beta M \\
	M=_\beta N\wedge N=_\beta L&\Rightarrow M=_\beta L
\end{align*}
We call a term $N$ a \emph{$\beta$-nf of $M$} if $M=_\beta N$ and $N$ is a $\beta$-nf.
From these definitions it follows (\cite{Barendregt} 3.1.10), that if $M$ is a
$\beta$-nf then $\neg\exists N:M\barrow N$ and $M\Barrow N\Rightarrow M\equiv N$.

The following example from \cite{Barendregt} p. 52 illustrates the concept:
\begin{align*}
	(\lam{x}{xx})(\lam{y}{y})z&\barrow(\lam{y}{y})(\lam{y}{y})z \\
	&\barrow(\lam{y}{y})z \\
	&\barrow z
\end{align*}
